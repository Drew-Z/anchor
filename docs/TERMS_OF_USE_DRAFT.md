# Anchor Learning 使用条款（发布前审阅稿）

状态：Private Alpha 候选稿，发布前必须由运营主体和法律顾问完成审阅并填写主体、联系渠道、生效日期、适用法律与争议处理方式。

## Private Alpha 边界

Anchor Learning 当前仅面向受邀 Android Private Alpha 测试者。功能、模型可用性和数据格式可能变化；除非发布方另有书面承诺，不提供持续可用性、跨设备同步或生产级服务等级保证。

## 用户责任

你必须对导入资料、导出文件和向模型服务商发送的内容拥有必要授权。不得导入违法、机密、个人敏感信息或第三方受限材料，除非你已取得处理和发送所需的许可。

模型生成内容仅供学习辅助。引用链和核验机制用于帮助检查来源，不构成专业、法律、医疗、财务或安全建议；你仍需自行核实并对使用结果负责。

## 模型与凭据

AI 功能依赖你选择并在应用内配置的模型服务。模型任务、配额、延迟、失败、服务条款及数据处理由相应服务商决定。不要共享凭据；若凭据泄露，应立即在服务商处撤销并在应用内删除模型配置。

## 反馈与问题

反馈和支持包仅在你确认导出后生成。诊断信息默认关闭，开启前会显示导出范围。对于崩溃、ANR、数据损坏、无法恢复或疑似凭据暴露，应停止继续操作并通过发布前填写的支持渠道报告。

## 终止与数据处理

你可随时停止测试，并使用“本地数据与隐私”导出或删除本机数据。卸载应用或删除本机数据不会删除已发送给外部模型服务商的数据；请依照该服务商的渠道处理相关请求。
