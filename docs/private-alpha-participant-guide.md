# Anchor Learning Private Alpha Participant Guide

## Before You Start

Use Anchor Learning only with a project that you own or are allowed to process. Do not use
employer-confidential code, production credentials, customer data, or private
third-party source material.

You need:

- a supported Android device;
- one local AI application project directory or ZIP;
- an API credential that you are authorized to use;
- approximately 35-45 minutes for the first session;
- time for a short D7 return and D14 interview.

Do not send your API Key to the study owner. Enter it only in the App's model
configuration screen.

## First Session

1. Install the provided APK and confirm the displayed version.
2. Choose project interview preparation.
3. Configure the assigned candidate model profile.
4. Run model acceptance. Continue AI learning only when the App shows `5/5`.
5. Import one permitted project and review included/excluded files.
6. Verify at least one learning unit and its source location.
7. Open the Agent workspace and answer one question in your own words.
8. Inspect the feedback and cited implementation.
9. Complete or schedule the selected next action.
10. Open the project interview outcome.

Please work as you normally would. A partial answer, refusal, confusing screen,
or inability to continue is useful study evidence.

## Sending Feedback

Use the feedback icon in first run, Agent workspace, project interview outcome,
or an error state.

The form always shows what will be exported. By default it includes:

- feedback category and severity;
- current screen;
- App and database version;
- the description you entered.

`Attach redacted diagnostics` is optional and off by default. When selected, it
adds version, database counts, privacy state, model acceptance summary, product
event summary, and stable diagnostic lines. It does not intentionally include
API Keys, source files, user answers, or raw model responses.

If you cancel the Android save dialog, no feedback event is recorded.

## D7 Return

Open Anchor Learning without help, review the next action, and complete one grounded
learning turn plus its follow-up or scheduled review. Export local product
events after finishing.

## Your Data

From `我的 -> 设置 -> 本地数据与隐私`, you can:

- inspect or disable local product events;
- export local events or a redacted support bundle;
- export and restore a database backup;
- delete selected learning data, events, model configuration, or first-run
  state.

You may stop participating at any time. Tell the study owner whether already
submitted files should be deleted. Deleting App data does not delete files that
you previously exported and sent outside the App.
