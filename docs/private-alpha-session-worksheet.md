# Duoduo Private Alpha Session Worksheet

## Storage Rule

Create one working copy per participant and phase outside the repository. Use
only participant codes and stable evidence locators. Do not record credentials,
real names, project names, private paths, source bodies, raw answers, or raw
model output.
