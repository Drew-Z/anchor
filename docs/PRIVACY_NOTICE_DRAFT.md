# Anchor Learning 隐私说明（发布前审阅稿）

状态：Private Alpha 候选稿，发布前必须由数据处理负责人和适用地区法律顾问审阅，并填入产品运营主体、联系邮箱、生效日期与适用地区。

## 数据存放与发送

Anchor Learning 将学习来源、知识点、题目、学习记录、Agent 会话和本地产品事件保存在设备本地 SQLite 数据库中。当前版本没有账户、云同步或跨设备合并。

当你主动配置模型并发起 AI 任务时，完成该任务所需的内容会发送给你选择的模型服务商。应用不会预置可供正式用户使用的共享模型凭据。请勿导入机密、未获授权或不应发送给该服务商的资料。

## 凭据与导出

模型凭据由系统安全存储保存，且不包含在数据库备份中。数据库备份包含学习内容、学习历史和本地产品事件；不包含模型凭据、模型配置、首次运行状态或隐私偏好。

你可从“我的 → 设置 → 本地数据与隐私”导出本地事件、脱敏支持包或数据库备份。支持包的 Agent 运行摘要默认关闭；应用不会在未确认系统保存对话框前生成反馈导出。

## 删除与恢复

同一页面允许删除学习历史、来源与学习内容、本地产品事件、模型配置与凭据或首次运行状态。数据库范围删除前可选择“直接删除”或“备份后删除”。恢复只接受完整且通过完整性验证的 Anchor Learning SQLite 备份；替换失败会自动回滚。

删除只影响本机受选范围，不能撤回此前已发送至你所选模型服务商的请求。模型服务商对数据的处理、留存和删除遵循其自身政策。
