# 导入你的学习资料

> 将个人笔记、技术文档、项目代码转化为可溯源的练习题

---

## 📁 支持的文件格式

### ✅ 完全支持
- **Markdown** (`.md`) - 推荐格式,解析效果最佳
- **Dart 代码** (`.dart`) - 自动提取类/方法/注释
- **纯文本** (`.txt`) - 基础文本内容

### 🚧 计划支持
- **PDF** - 需要 OCR 转文本
- **代码多语言** (`.js`, `.py`, `.java`, `.go`) - 通用代码解析
- **Notion 导出** - JSON 格式导入

## 🎯 文档准备建议

### 1. 使用清晰的标题结构

**推荐格式**:
```markdown
# 主题名称

## 第一章:基础概念

### 1.1 核心概念 A
内容...

### 1.2 核心概念 B
内容...

## 第二章:实战应用

### 2.1 场景 A
内容...
```

**为什么**: AI 会按章节切分内容,标题层级清晰能提高知识点提取准确度

### 2. 代码块标注语言

**推荐**:
````markdown
```dart
class Example {
  // 代码
}
```
````

**避免**:
````markdown
```
class Example {
  // 没标注语言
}
```
````

**为什么**: 语言标注帮助 AI 生成语法正确的填空题

### 3. 保留关键细节

**推荐**: 包含具体数字、配置项、命令
```markdown
Flutter 默认使用 `60 FPS` 刷新率。
使用 `flutter run --release` 构建生产版本。
```

**避免**: 过于抽象的描述
```markdown
Flutter 性能很好。
使用命令构建应用。
```

**为什么**: 具体细节会转化为更有区分度的练习题

## 📋 导入流程详解

### 方式 1: 单文件导入

1. **打开 APP → 导入页面**
2. **选择文件**
   - 点击"选择 Markdown 文件"
   - 从设备文件系统选择
3. **预览内容**
   - 查看文档标题、字数
   - 确认是否包含代码块
4. **点击"开始分析"**
5. **等待处理**(通常 30 秒 - 2 分钟)

**处理过程**:
```
文档解析 → 语义切分 → 知识点提取 → 题目生成 → 质量验证
```

### 方式 2: 项目目录导入

1. **打开 APP → 导入页面 → 项目导入**
2. **选择项目根目录**
3. **配置扫描选项**:
   - 包含的文件扩展名(`.dart`, `.md`)
   - 排除目录(`node_modules`, `build`, `.git`)
4. **开始扫描**
5. **AI 分析项目结构**:
   - 识别入口文件
   - 提取架构模式
   - 生成代码理解题目

## 🎨 目录结构最佳实践

### 个人学习笔记

```
my-learning-notes/
├── flutter/
│   ├── 01-basics.md          # 基础概念
│   ├── 02-widgets.md         # 组件系统
│   └── 03-state-management.md # 状态管理
├── dart/
│   ├── async.md              # 异步编程
│   └── null-safety.md        # 空安全
└── projects/
    └── my-app/               # 实战项目代码
```

**导入顺序建议**:
1. 先导入基础概念文档(`flutter/01-basics.md`)
2. 再导入进阶主题
3. 最后导入项目代码

### 技术书籍/课程

```
book-name/
├── chapter-01.md
├── chapter-02.md
├── chapter-03.md
└── code-examples/
    ├── example-1.dart
    └── example-2.dart
```

**建议**: 
- 每章单独导入,便于分阶段学习
- 代码示例与章节关联(在 Markdown 中引用)

## 🔍 导入后检查清单

### ✅ 验证知识点

1. **进入"知识库"页面**
2. **检查提取的知识点**:
   - 标题是否准确?
   - 描述是否完整?
   - 分类是否合理?(概念/架构/实现)
3. **查看原文引用**:
   - 点击知识点 → 查看"来源片段"
   - 确认引用内容是否相关

### ✅ 测试练习题

1. **进入"练习"页面**
2. **随机做几道题**:
   - 题目是否清晰?
   - 选项是否有区分度?
   - 答案解析是否引用原文?
3. **故意选错,查看反馈**:
   - 错误解释是否准确?
   - 是否显示正确答案来源?

### ❌ 常见问题修复

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 没有生成题目 | 文档太短或无结构 | 增加内容或添加章节标题 |
| 题目与内容无关 | 语义切分错误 | 检查 Markdown 格式(标题层级) |
| 代码填空题语法错误 | 代码块未标注语言 | 重新导入,确保 \`\`\`dart 标注 |
| 知识点重复 | 多次导入同一文件 | 删除旧导入,重新分析 |

## 🛠️ 高级技巧

### 1. 为特定主题生成题目

**编辑文档,添加显式知识点标记**:
```markdown
## 核心概念:单例模式

<!-- knowledge-point: 单例模式的实现方式 -->
Dart 中实现单例可以使用 factory 构造函数...
```

**效果**: AI 会优先为标记的段落生成题目

### 2. 控制题目难度

**在文档中添加难度提示**:
```markdown
## 基础:变量声明 <!-- difficulty: easy -->
内容...

## 进阶:泛型约束 <!-- difficulty: hard -->
内容...
```

### 3. 关联多个文档

**使用内部链接**:
```markdown
# 状态管理

前置知识:[Widget 生命周期](./widgets.md#lifecycle)

详细内容...
```

**效果**: AI 会提取知识点依赖关系,按顺序推荐学习
