## 📋 漂移项

### 1. PDF 文档支持

- **文档位置**: ROADMAP.md - v0.3 近期计划
- **文档描述**: "PDF 文档支持 - OCR 文本提取,保留格式和图片引用"
- **代码现状**: 未实现。当前仅支持 Markdown 文件导入
- **影响**: 用户无法导入 PDF 格式的学习资料
- **状态**: 规划中,优先级:高

---

### 2. 本地 LLM 支持

- **文档位置**: ROADMAP.md - v0.3 近期计划
- **文档描述**: "本地 LLM 支持 - Ollama 集成,LM Studio 支持,完全离线运行"
- **代码现状**: 仅支持 OpenAI API (`lib/services/openai_service.dart`)
- **影响**: 用户必须联网并配置 OpenAI API Key 才能使用
- **状态**: 规划中,优先级:高

---

### 3. 多语言代码解析

- **文档位置**: ROADMAP.md - v0.3 近期计划
- **文档描述**: "支持 JavaScript/TypeScript/Python/Java/Kotlin/Go"
- **代码现状**: 代码导入功能存在但无语言特定解析 (`lib/features/ingestion/`)
- **影响**: 导入非 Dart 项目时效果可能不佳
- **状态**: 规划中,优先级:高

---

### 4. 知识图谱可视化

- **文档位置**: ROADMAP.md - v0.3 近期计划
- **文档描述**: "展示知识点依赖关系,可交互的学习路径"
- **代码现状**: 数据模型中有 `prerequisites` 字段,但无可视化界面
- **影响**: 用户无法直观看到知识点之间的依赖关系
- **状态**: 规划中,优先级:中

---

### 5. 错题本功能

- **文档位置**: ROADMAP.md - v0.3 近期计划
- **文档描述**: "自动收集错题,错误原因分析,针对性复习"
- **代码现状**: `StudyRecord` 表记录答题历史,但无错题本专门入口
- **影响**: 用户需要手动在历史记录中查找错题
- **状态**: 规划中,优先级:高

---

### 6. Web 版本

- **文档位置**: ROADMAP.md - v1.0 中期计划
- **文档描述**: "浏览器内运行,云同步功能,多设备协同"
- **代码现状**: 仅有 Flutter 移动端和桌面端
- **影响**: 无法在浏览器中使用
- **状态**: 长期规划,优先级:高

### 7. 社区题库

## 🔍 如何使用本文档

### 对于用户
- 看到"未实现"的功能,请暂时不要依赖
- 如果某个功能对你很重要,可以在 [GitHub Discussions](https://github.com/Drew-Z/anchor/discussions) 投票

### 对于贡献者
- 这些是很好的贡献方向
- 实现漂移项后,请更新本文档到"已解决"部分
- 发现新的漂移? 欢迎提 PR 补充

### 对于项目维护者
- 每次更新 ROADMAP.md 后,检查本文档
- 每次实现路线图功能后,移动到"已解决"部分
