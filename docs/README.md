## 🎯 常见问题

### 使用问题

**Q: 导入文档后没有生成题目?**
A: 可能原因是文档太短或格式不规范。参见[导入文档指南](guides/IMPORT_YOUR_DOCS.md#troubleshooting)。

**Q: 如何备份我的数据?**
A: 设置 → 隐私与数据 → 导出数据,生成 JSON 备份文件。

**Q: 可以不用官方 OpenAI 服务吗?**
A: 可以。应用支持符合 OpenAI-compatible 协议的自定义、本地或自托管端点；请在设置中填写 Base URL、模型名和凭据,并先通过应用内验收。

### 开发问题

**Q: 如何调试 AI Prompt?**
A: 参见[自定义 Prompt - 调试技巧](guides/CUSTOMIZE_PROMPTS.md#10-调试技巧)。

**Q: 如何添加新题型?**
A: 参见[自定义 Prompt - 添加自定义题型](guides/CUSTOMIZE_PROMPTS.md#7-添加自定义题型)。
