# Anchor Learning 数据删除说明

在 App 中打开“我的 → 设置 → 本地数据与隐私 → 选择删除范围”。删除操作需明确选择范围并确认。

| 删除范围 | 删除内容 | 保留内容 |
| --- | --- | --- |
| 学习历史 | 学习会话、回答与评价、复习记录、Agent checkpoint/trace | 来源、知识点、题目、模型配置 |
| 来源与学习内容 | 来源、片段、知识点、题目、练习及关联学习历史 | 模型配置、首次运行状态、隐私偏好 |
| 本地产品事件 | 本地事件和匿名安装 ID | 学习内容、模型配置；操作完成后仅保留新的 `data_deleted` 审计事件 |
| 模型配置与凭据 | provider、endpoint、协议、模型、验收记录和安全存储凭据 | 学习数据库和首次运行状态 |
| 首次运行状态 | 目标选择和首次运行进度 | 学习数据库、模型配置和隐私偏好 |

## 备份、删除和恢复

删除任一数据库范围时，应用会提供“取消”“直接删除”“备份后删除”。选择“备份后删除”后，只有系统文件保存完成才会开始删除；取消系统保存不删除任何数据。

数据库备份只包含本地 SQLite 数据：学习内容、学习历史和本地产品事件。它不包含模型凭据、模型配置、首次运行状态或隐私偏好。恢复会替换这些数据库范围，先进行完整性和 schema 检查；失败时应用回滚到替换前数据。

删除本机数据不能撤销已由你主动发给外部模型服务商的内容。需要处理该类数据时，请使用对应服务商的隐私或删除渠道。
