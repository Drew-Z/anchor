## 🚀 如何使用

### 在应用中导入示例

1. 打开"Anchor Learning (锚学)" APP
2. 点击底部导航栏的 **"导入"**
3. 选择 **"选择 Markdown 文件"**
4. 导航到项目目录: `assets/examples/`
5. 选择任一 `.md` 文件
6. 等待 AI 分析 (约 30-60 秒)
7. 完成后进入 **"练习"** 页面开始学习

### 预期效果

每个示例文件会生成:
- **知识点**: 文档中的核心概念提取
- **练习题**: 单选/填空/判断题 (每个知识点 2-3 道)
- **来源链接**: 每道题都能追溯到原文档位置

### 体验溯源功能

1. 答题后查看解析
2. 点击 **"查看来源"** 按钮
3. 跳转到原文档的对应位置
4. 理解题目的上下文

## 🎯 示例数据的设计原则

### 1. 完整性
- 每个示例都是完整的知识单元
- 不依赖外部文档
- 可以独立学习

### 2. 层次性
- 标题层级清晰 (用 `##` 和 `###`)
- 方便 AI 进行语义切分

### 3. 实用性
- 真实的技术场景
- 包含代码示例
- 有常见错误提示

### 4. 可溯源性
- 每个知识点都有明确的位置
- 使用清晰的标题作为 locator

## 📝 贡献新示例

欢迎提交新的示例数据! 要求:

### 格式规范
```markdown
# 主题标题

> 简短描述

## 一级知识点

### 二级知识点

内容...

代码示例 (如果适用):
```language
code here
```

常见错误/注意事项...
```

### 质量标准
- 知识点数量: 8-15 个
- 字数: 1000-3000 字
- 代码示例: 至少 3 个
- 错误示例: 至少 2 个
- 无拼写错误
- 技术准确性高

### 提交方式
1. Fork 项目
2. 添加 `.md` 文件到 `assets/examples/`
3. 更新本 `README.md`
4. 提交 PR

## 🔗 扩展资源

### 自己制作示例的建议

如果你想为自己的学习领域制作示例:

1. **选择主题**: 一个明确的技术主题 (不要太宽泛)
2. **结构化组织**: 使用清晰的标题层级
3. **包含代码**: 理论 + 实践结合
4. **标注易错点**: 帮助 AI 生成更好的题目

### 最佳实践
- ✅ 每个 `##` 标题是一个知识点
- ✅ 代码用三个反引号包裹并标注语言
- ✅ 避免过多嵌套层级 (最多 3 层)
- ✅ 关键术语用**加粗**突出
- ❌ 不要用图片 (暂不支持)
- ❌ 不要用表格 (可能切分不佳)
